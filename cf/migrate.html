Copy images into R2

Supabase Storage → the Cloudflare Worker, for collections that already have their cards in /cf/ but no image files behind them.

This never writes the collection document. It only adds image objects, and it skips anything already in R2 — so it is safe to run twice, and safe to stop and resume. Your cards, folders and notes in /cf/ are not read from Supabase and cannot be overwritten by it.
